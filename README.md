# OVERDRIVE // VECTOR BREAK — FLAT ARENA TEST

**v2.0-alpha2-flat · 2026-11-07**

プレイテストで報告された「遮蔽物が多すぎる」「内部への幽閉」「開始地点の点滅」を切り分けるための更地版。

## 変更内容

- **障害物10個、高所足場9個、ジャンプパッド4個をすべて撤去**。
- 中央の発光リング、立柱14本、床のグリッド線、外周の装飾ライトも撤去。
- アリーナ内は平らな床のみ。外周を囲む4面の壁と境界判定は残す。
- 地上移動・飛行・射撃・敵弾の遮蔽判定を空の地形データに揃え、飛行と着地を検証。
- **敵の難易度、銃のモデル、FLOW DRIVEの性能は今回は変更なし**。次の段階で調整予定。

## プレイ方法

[GitHub Pages](https://toraigon91412250-png.github.io/atarasiige-mu/) でプレイ。PCはWASD・マウス・Space（ジャンプ）・E（覚醒）、スマホは画面上の移動／射撃／JUMP／DRIVEボタンを使用。覚醒中はジャンプ長押しで上昇する。

## テスト

障害物撤去後の14地点通行、ジェット飛行と着地、境界制御、6セクター進行、後退入力、Chromiumタッチ操作を自動検証。テストコードは配布ソースZIPに同梱。

実GPUでの点滅解消とiPhone Safari実機での快適性は未確認。前のバージョンは `archive/flow-drive-v2-alpha1-20261107` ブランチに保存済み。
